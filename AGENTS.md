# Workout Tracker working agreement

These instructions apply throughout this repository, including workout coaching
and planning requested in its tasks. The dashboard itself remains read-only as
described in README.md; coaching instructions do not add application features or
authorize unrequested workbook edits.

## Follow 5/3/1 as the default session structure

- Build strength workouts around the user's current 5/3/1 program in the 531
  spreadsheet. Read the current training maxes, prescribed main and supplemental
  work, and completed sessions before selecting the day's work.
- Monday arm day is bench-led: bench is the main lift, followed by the program's
  supplemental work and assistance selected around that lift and the user's
  arm emphasis. "Arm day" does not mean replacing bench with an isolation-only
  biceps/triceps session.
- Present the main lift's warm-ups and 5/3/1 working sets first, then supplemental
  work, then assistance. Derive loads and reps from the current spreadsheet and
  confirmed progression; do not advance the program week merely because a new
  calendar week has begun.
- Use a cardio-focused or circuit-style workout instead only when the user
  explicitly requests that type of session. Do not independently substitute
  either for the scheduled 5/3/1 strength workout.
- Symptoms and recovery still matter. If they may prevent the planned main lift,
  clarify the current symptoms and explain any necessary adjustment; do not
  silently replace the program with a different workout or force symptomatic
  lifting.

## Always show weights and plates (SOP)

- Whenever prescribing barbell loads, including warm-ups, main sets,
  supplemental sets, and live set-by-set coaching, always give total weight
  including the bar, sets/reps, and the exact plates to load on EACH side.
  Do not wait for the user to request plate math.
- State the bar weight used. Use the confirmed bar weight when known; otherwise
  clearly label a 45-lb bar as an assumption and recalculate if corrected.
- Check that bar weight plus twice the per-side plate total equals the stated
  total. Use available plate denominations when known; do not imply unverified
  equipment availability. Preserve the established rounding-down rule when
  exact prescribed loads cannot be assembled.
- For dumbbells, state weight per hand; for machines, state the stack or loading
  convention rather than presenting barbell plate math.

## Automatically assess the training challenge

The user wants challenging, productive training that advances their goals.
Assess whether every proposed workout provides an appropriate training stimulus
before presenting or saving it. The user should not have to request this review
or point out that a carried-forward workout is too light.

1. Read the current goal, program, completed sessions, individual sets, and relevant
   recovery context. Use actual loads, reps, rep quality, reps in reserve (RIR),
   equipment, and rest where recorded. Distinguish demonstrated performance from
   old prescriptions and uncompleted plans; leave unknown facts unknown.
2. Evaluate the whole session against the user's demonstrated capacity and current
   program: exercise coverage, working sets per muscle group, load, rep targets,
   proximity to failure, rest periods, and surrounding training volume. Count
   warm-ups separately. Familiar weights and a list of exercises do not establish
   an adequate challenge, and one hard set does not establish a demanding session.
3. Compare the proposed workload with comparable completed sessions. Decide what
   should progress: load, reps, productive working sets, or another variable that
   serves the goal. State a concrete target and the performance criterion for the
   next increase. Holding steady can be appropriate, but explain the evidence for
   it rather than silently repeating the existing plan.
4. If the plan undershoots demonstrated capacity or the intended training demand,
   revise it before presenting it. Do not default to a novice or recovery workout
   simply because it is easy to complete, uses familiar exercises, or the recorded
   dates are old. Use the smallest justified changes that make the session
   sufficiently challenging; extra exercises and exhaustion are not goals by
   themselves.
5. Account for actual fatigue, symptoms, technique, and program progression when
   selecting the challenge. Explain a lighter session when the evidence warrants
   one. Do not interpret the preference for hard training as an instruction to
   ignore symptoms, force failed reps, or increase every variable at once.
6. Present the workout with a brief explanation of why its total demand fits the
   user, what represents progress, and how actual set performance will guide
   adjustments. Do this automatically, without adding a separate approval gate
   for routine planning decisions already within the user's request.

## Ground recommendations and corrections

- Treat an existing next-workout plan as a candidate to evaluate, not proof that
  its workload or exercise selection is appropriate.
- Identify new exercises as proposals, not established habits or completed work.
  Keep explicitly rejected exercises out of subsequent plans unless the user
  revisits that decision.
- Keep planned work separate from performed-work logs. Record only confirmed
  completed work and preserve unknown values as unknown.
- When challenged, recheck the actual workload and performance evidence. Correct
  unsupported conclusions directly; do not reflexively agree, flatter the user,
  or assign novice/intermediate/advanced labels from a workout alone. Distinguish
  lifting workload from broader athleticism when that distinction is relevant.

## Planning regression check

Before finalizing a workout, verify that it follows the 5/3/1 main lift and
supplemental structure unless the user explicitly requested a cardio or circuit
session, and that any symptom-related adjustment is explained. Then check:
What demonstrated
capacity is this based on? Is the complete session challenging enough for the
goal? What progresses, or why is it held steady? What performance will determine
the next adjustment? A copied plan with only its date changed fails this check
unless the workload has been independently evaluated and retaining it is
supported by the current evidence.
